# 任务卡 · HR-07 拜访周评 / 销售周评（每人一段，给老板和主管）

> 出卡日期：2026-10-28。用户决定：agent 方向先做"拜访周评 + 销售教练"（优先于远程拓展）。
> 依赖：HR-04 v3 拜访导入（已上线）、订单 / 发票 / 回款表、回访清单（customer_insights）。
> 在现有「周报 + AI 周评」（`VisitImport::digest`，全队一段话）之上加一层：**按人**、**跨数据源**、**每周一自动出**、**只说该做的事**。
> 原则：评语给老板和主管看，**不给销售本人**，不排名、不判罚（第二原则）；数字全由规则算，AI 只写评语和建议，每周 < 1 美元。

---

## 一、每周一 07:00 自动生成（服务器 cron，复用 nightly.php 的入口）
周期 = 上周一到周日（与 HR-04 周报一致）。生成一份 `sales_reviews` 记录（周 + 全队总览 + 每人一段），写一条 `hr_todos` 给老板「上周销售周评已生成」（类型 `sales_review`，仅老板；主管在页面看，不推待办）。手动按钮「重新生成」只给老板。

## 二、每人一段，固定四块（规则算数，AI 写两三句）
数据按 `employees` 里 `attendance_mode = 拜访` 的在职销售，一人一段：
1. **跑动**：本周拜访数、新店数（Baru）、老客户数、与上周比；结果分布（Minat / Penawaran / Order / Tidak / Tutup / 未知）；有标签比例。
2. **该跟的**：报价（Penawaran）超过 7 天没有后续拜访或订单的店，列名（最多 8 家，按报价日期）；回访清单上分配给他、本周未动的 A 类客户数。
3. **成果**：本周成单（订单数、张数、含税金额，口径同看板）、出货、回款（payments 按回款日期）；逾期未收且是他名下客户的发票金额。
4. **评语**（AI，`sales_review` 任务）：两三句，说清一件事——这周最值得做的下一步（如"报价 5 家没跟，先回访这几家"、"新店多但成单少，带样品回访"）。不夸不批，不与他人比较。

全队总览一段（AI）：谁在跑、谁停了（本周 0 拜访的在职销售只点名不评价）、哪个区域出单、竞品价格有没有变（沿用现有 digest 的输入）。

## 三、数据表
### `sales_reviews`
- `week`（周一日期，YYYY-MM-DD）、`generated_at`、`generated_by`（cron / 用户名）
- `team_zh`、`team_id`（全队总览两种语言）
- `data_json`（当周算好的全部数字，便于复算与审计）
- `ai_call_id`（ai_calls 外键，可空）、`status`（ok / ai_skipped：AI 关闭或超预算时只有数字，评语空）

### `sales_review_items`
- `review_id`、`employee_id`、`metrics_json`（第 1–3 块的数字与名单）、`comment_zh`、`comment_id`
- 一周一人一行，UNIQUE(review_id, employee_id)

## 四、页面
入口：人力菜单下「销售周评 / Review Mingguan」；老板和 `visits_all` 可见全部，部门主管只看本部门（沿用 HR 的 scope）。
1. 周选择（默认上周）→ 顶部全队总览（中/印尼随界面语言）→ 每人一张卡：四块数字 + 名单 + 评语。
2. 「该跟的」名单里每家店可点进客户 / 潜客页。
3. 导出 Excel：一周一个文件，每人一行数字 + 评语两列（给主管在例会用）。
4. 不做趋势图；上周对比只用箭头和数字。

## 五、规则与口径
- 拜访 = `visits` 表 `source` 不限，`employee_id` 非空；未映射发送者的拜访不计入任何人，总览里注明条数。
- 报价未跟 = 某店最近一次 outcome = penawaran 的拜访距周末 > 7 天，且之后该店（customer_id / prospect_id）没有新拜访、没有该客户的新订单。
- 成单口径与看板一致：订单按 `submitter` 归人、按下单日期计数；销售额按发票日期；回款按 `payments` 日期，经发票归到订单的 submitter。
- 发给模型的只有数字、店名、客户名；不含电话、地址、金额以外的财务数据。
- AI 关闭 / 超预算：数字照常生成，评语栏显示「本周无评语」，不重试。
- 评语存档后不再改；重新生成会新建一条记录，旧的保留（审计）。

## 六、验收
- 用过去两周的真实导入数据生成，每个销售一段，数字与 HR-04 周报、看板一致（抽 2 人核对）。
- 报价未跟名单里的店，在拜访记录里确实是 penawaran 且之后无动作。
- AI 关闭时页面照常出数字；开启时评语两种语言都有，长度 ≤ 3 句。
- 周一 07:00 cron 跑完老板待办里有一条；重复跑同一周不重复建。
- 销售账号看不到此菜单。

## 七、不做
给销售本人的推送、排名榜、KPI 打分、提成计算（人力二期）、WhatsApp 推送（渠道待定后再接）、趋势图表。
