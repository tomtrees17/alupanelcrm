# 任务卡 · HR-01~03 收尾调整（按"不加负担"原则）

> 人力一期已由 Claude Code 完成。上线前做以下小改，目的：HR 只是把现有 Excel 和纸质资料搬进系统，不被系统催着补东西。
> 出卡日期：2026-10-21

## 改动清单
1. **去掉"资料完整度低于 80% 标黄"**。完整度数字保留在详情页，列表页不做任何颜色提示
2. **新增员工的必填项减到三个**：姓名、NIK、入职日期。部门、职位、工作地、出生日期改为可后补
3. **待办中心只保留四类**：合同即将到期 / 合同已到期未处理 / BPJS 逾期未登记 / 离职待停保。其余提醒（试用期到期等）保留数据但不生成待办
4. **批量导入**：员工档案、合同、BPJS 三张表各加一个 Excel 导入入口，模板列名与 HR 现有 Excel 一致（由 HR 提供现用表，Claude Code 按它定模板）。附件可以后补，不影响导入
5. **离职流程保持一键**，这是减少工作的，不动

## 验收
- HR 用现有 Excel 一次导入全部员工，不需要逐个手输
- 新建员工只填三项即可保存
- 列表页无黄色标记；首页待办只出现上述四类
