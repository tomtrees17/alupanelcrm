# 任务卡 · HR-04 拜访记录 / Catatan Kunjungan（替代 Excel 回收表）

> 排在人力一期之后开发。依赖 HR-01 员工表、现有 CRM 客户表、客户分析模块的地址坐标。
> 目标：**把销售现在每周填的 Excel 拜访回收表搬到手机上，字段一样，不多填一项。** 周报自动生成，周五不再回收 Excel。
> 原则：销售的操作量只减不增。定位在后台静默采集，不要求拍照，不要求签退。
> 出卡日期：2026-10-21（v2，按"不加负担"原则简化）

---

## 一、销售端：一个表单，和 Excel 一样的字段
手机浏览器打开 CRM，入口「拜访 / Kunjungan」，仅 `attendance_mode = 拜访` 的员工可见。页面按手机宽度设计，支持添加到主屏幕。

**新增一条拜访**（对应 Excel 回收表的一行）：
1. 客户：从「我的客户」或「潜客名单」里选，带搜索；名单里没有的直接输名字
2. 结果：四个大按钮 Berminat / Tidak Butuh / Follow-up / Sudah Dikirim Penawaran
3. 备注：可选
4. Tidak Butuh 时多显示两格：现用供应商、价格（可选，不填不拦）
5. 保存

就这五步，和他们现在在 Excel 里填的一样。拍照按钮放在表单最下面，**可选**。

**后台静默采集**（销售无感知，不增加操作）：
- 保存时若浏览器已授权定位，记录坐标与精度；未授权不提示、不阻止
- 自动记录保存时间
- 自动算与客户地址的距离（有坐标时）

**不做**：签到/签退两次操作、必拍照、本周进度条、未签退提醒。

## 二、数据表
### `employees` 新增
- `attendance_mode`：打卡 / 拜访；销售默认拜访

### `visits`
- `visit_no`、`employee_id`、`visited_at`（保存时间，可手改日期以补录前几天的）
- `target_type`（客户 / 潜客 / 新客）、`customer_id` 或 `prospect_id` 或 `new_customer_name`
- `outcome`、`note`、`current_supplier`、`current_price`
- `photo_path`（可空）
- `lat`、`lng`、`accuracy`、`distance_m`、`distance_flag`（正常 / 偏远 / 无坐标）—— 全部可空
- 审计字段同 HR-00；保存后 24 小时内可改，之后锁定

### `prospects`（潜客池最小版）
- 从 450 家名单 Excel 导入：名称、类型、地址、坐标、区域、行业、电话
- `assigned_to`、`last_visit_at`、`last_outcome`、`visit_count`
- 画像与打分留给后续任务

## 三、后台（主管 / 老板）：只看，不操作
1. 拜访列表：日期、销售、客户、结果；筛选销售 / 日期 / 结果
2. 周报表：每销售本周拜访数、各结果占比、新客数；**格式与现有 Excel 回收表完全一致**，可导出
3. 地图视图：有坐标的拜访点落在客户分析模块的现有地图上，按销售着色
4. 距离偏远的记录在列表里淡色标记，仅供参考，不生成待办、不要求复核

## 四、联动
- 保存后自动在 CRM 客户跟进记录或潜客记录追加一条"拜访"
- 客户分析「该回访 / 快流失」读取 `visits.visited_at` 更新"最近接触日"
- 周五 17:00 自动生成周报，写入 `hr_todos` 给老板一条「本周拜访周报已生成」

## 五、验收
- 销售在手机上 30 秒内完成一条记录（选客户 → 点结果 → 保存）
- 周报表导出的列与现有 Excel 回收表一一对应，可直接替代
- 未授权定位的手机照样能保存记录
- 450 家潜客导入后可在选客户时搜到

## 六、不做
签到签退、必拍照、办公室打卡、离线、人脸识别、路线规划、里程报销、异常复核流程
