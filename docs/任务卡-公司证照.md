## 数据表 `company_licenses`
- `doc_type`：类型，下拉，由 HR 在配置页维护。预置：
  - 公司主体：NIB / NPWP 公司 / Akta Pendirian / Akta Perubahan / SK Kemenkumham / SPPKP（PKP 登记）
  - 经营许可：行业许可 / 产品认证 / 仓库与场地相关许可 / 环保相关许可
  - 外籍人员：RPTKA / KITAS / 工作签证 / 其他准证
  - 车辆：STNK（年检税）/ STNK（五年换牌）
  - 其他
- `name` 证照名称、`doc_no` 证号、`issuer` 发证机关
- `holder_employee_id`：持有人（外籍准证等指向 `employees`，可空）；`holder_text`（非员工持有人或车辆，填文字，如车牌号）
- `issue_date`、`expiry_date`（空 = 长期有效）、`remind_days`（默认 60，可逐条改；KITAS 建议 90）
- `pic_employee_id` 负责跟进的人、`storage` 原件存放位置、`note`
- `status`：有效 / 已更新（被新证取代）/ 已注销
- `previous_license_id`：续期时指向上一张
- 扫描件：存私有目录 `data/legal/{id}/`，鉴权下载，规则同 HR-00 附件
- `created_by / created_at / updated_by / updated_at`；**不可物理删除**，改动写 `audit_log`

**有效状态实时算，不存库**：
- 长期有效：`expiry_date` 为空
- 已过期：`expiry_date < 今天`
- 即将到期：`expiry_date ≤ 今天 + remind_days`
- 有效：其余

## 页面
1. 列表：类型、名称、证号、持有人、到期日、剩余天数、有效状态、负责人；顶部四个数字（有效 / 即将到期 / 已过期 / 长期有效），点数字即筛选；按到期日升序，长期有效排最后
2. 详情：全部字段 + 扫描件 + 续期链条（历次证照）+ 改动日志
3. 「续期」按钮：新建一条，自动带出类型、名称、持有人、负责人，旧证状态改「已更新」。一步完成
4. 员工详情页新增「准证」页签：显示以该员工为持有人的证照
5. Excel 批量导入（与人力一期收尾第 4 条同一机制），扫描件可后补

## 待办（接入现有 `hr_todos`）
- 新增两类：「证照即将到期」（进入 remind_days 窗口当天生成，一条证只生成一次）、「证照已过期未处理」（到期次日仍无续期或注销记录，标红）
- 待办给 HR 和老板，不给一线员工；做了续期或注销，待办自动关闭
- 人力一期收尾把待办限定为四类，本卡在此基础上加这两类，共六类

## 规则
- 同一 `doc_type + doc_no` 只能有一条「有效」记录
- 到期日不能早于签发日
- 外籍准证必须选持有人员工；该员工离职时，其名下准证生成待办「离职员工准证待注销」（并入「证照已过期未处理」这一类显示，不另加类型）

## 验收
