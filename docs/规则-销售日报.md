# 规则 · 销售日报（WhatsApp 群「Absensi Team Sales」）

> 2026-10-24 定稿，**同日决定暂不推行**：老板要求不改变销售习惯，系统先用 AI 解析现有自由文本（HR-04 v3 `visit_parse`）。本规则保留，待解析准确率或信息缺口说明有必要时再发到群里。群里只有日报，没有闲聊和指令。
> 原则：在销售已经在发的内容（带水印照片 + 店名）上，只把那句模板话换成三个有信息量的词。

## 格式（一家店一条，当天发）

```
[照片：带时间与地址水印的相机，如 Timestamp Camera]
Toko: <店名，按招牌写>
Status: Lama / Baru
Hasil: Minat / Penawaran / Order / Tidak / Tutup
Catatan: <可不写> 需求数量与时间；竞品牌子与价格
```

- 前三行必填，Catatan 自愿
- 几家店不合成一条
- 补发的在第一行写日期（如 `23/10`）
- Hasil = Tidak 时尽量写现用牌子和价格（《Petunjuk Program Kunjungan》原有要求）
- 不要求日终总结、签到签退、回复确认；汇总由系统做

## 字段含义
| 字段 | 用途 |
|---|---|
| 照片水印 | 时间、地址 → 系统定位与核时，销售不填 |
| Toko | 对上 CRM 客户或潜客名单 |
| Status | 维护老客 / 开发新店 的比例 |
| Hasil | Minat 有意向 / Penawaran 已报价 / Order 拿到订单 / Tidak 不需要 / Tutup 没见到人或店关门。系统存为 Berminat / Sudah Penawaran / Order / Tidak Butuh / Tidak Terhubung（与原 Excel 一致 + Order） |
| Catatan | 需求预测与竞品分析原料 |

## 发给群的印尼语版
Mulai Senin, laporan kunjungan di grup ini pakai format berikut, satu toko satu pesan, dikirim hari itu juga:

📷 Foto (pakai kamera timestamp seperti biasa)
Toko: nama toko
Status: Lama / Baru
Hasil: Minat / Penawaran / Order / Tidak / Tutup
Catatan: kebutuhan, jumlah, merek & harga yang dipakai sekarang (kalau ada)

Kalau Tidak, tolong tulis merek dan harga yang mereka pakai sekarang. Tidak perlu rekap akhir hari, sistem yang merangkum.

- 群聊导出（含媒体）为输入；一条"照片 + Toko 行"识别为一次拜访；旧格式（模板话、无 Hasil）也要能解析，Hasil 标「未知」

- 不判罚、不催填；格式不对的只在主管视图淡色标记
