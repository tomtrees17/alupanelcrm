# 规则 · 销售日报（WhatsApp 群「Absensi Team Sales」）

> v2，2026-10-24。原 v1 的四行固定格式作废（改习惯成本高）。现行规则：**汇报内容照旧自由写，只在末尾加标签**。忘了加标签的汇报照样进系统，由 AI 解析，不漏、不判罚。
> 目的不是省 AI 费用（每月约 400 条，不到 1 美元），而是让"新老客户 / 结果 / 竞品"三项不靠猜，口径一致、可核对。

## 销售怎么发（不变的部分）
- 一家店一条消息；照片用带时间地址水印的相机；说明写在第一张图的 caption 里
- 店名写第一行，按招牌写
- 叙述自由：PIC、聊了什么、需求数量和时间、对方现用品牌和价格
- 当天发；不要求日终总结、签到签退、回复确认

## 末尾标签（新增，忘了也没事）
| 标签 | 含义 | 系统存为 |
|---|---|---|
| `#Lama` / `#Baru` | 老客户 / 新店 | status_lama_baru |
| `#Minat` | 有意向 | Berminat |
| `#Penawaran` | 已报价 | Sudah Penawaran |
| `#Order` | 拿到订单 | Order |
| `#Tidak` | 不需要 | Tidak Butuh |
| `#Tutup` | 没见到人 / 店关门 | Tidak Terhubung |
| `#Marks` `#Tajima` `#Seven` `#Alcopan` `#Toin` … | 对方现用品牌（可选，可多个） | competitor_brand |

示例：
```
Anugrah Aluminium
Workshop
Pic : Bpk Riswanto
Penawaran Alusign, rencana ada kebutuhan di serat kayu, sdh berikan katalog dan sample
#Baru #Minat #Marks
```

## 发给群的印尼语版
Tambahan kecil: di **akhir laporan** tolong tambahkan tagar, supaya sistem baca lebih cepat dan tepat. Isi laporan tetap bebas seperti biasa.

• **#Lama** atau **#Baru** (pelanggan lama / toko baru)
• Hasil: **#Minat #Penawaran #Order #Tidak #Tutup** (pilih satu)
• Merek yang mereka pakai sekarang, kalau ada: **#Marks #Tajima #Seven** dst.

Contoh: `#Baru #Minat #Marks`
Lupa pasang tagar tidak apa-apa, laporan tetap masuk.

## 系统侧约定（供 HR-04 v3）
- 解析顺序：先认标签（大小写不敏感，`#` 可省略但建议带）→ 店名取第一行 → 品牌按已知品牌表正则 → 以上有缺的字段才调 AI `visit_parse`
- 标签与 AI 推断都有时以标签为准；AI 结果只填空缺
- 未知品牌标签（如 `#Alucobond`）进待确认列表，主管确认后加入品牌表
- 发送者手机号 / 昵称 ↔ 员工映射由 HR 维护一次
- 不判罚、不催填；没标签的只在质量指标里计数
